# MustBuy — Shopify theme

A high-converting Online Store 2.0 theme, built in Hebrew (RTL), for the Must Buy It store.

## Conversion features
- Rotating announcement bar and a sticky header
- Hero with a CTA, badge, and a social-proof line
- Trust bar, comparison table ("us vs. them"), reviews, and FAQ (with FAQ schema)
- Countdown timer ("today only" that resets nightly, or until a specific date)
- Product card: discount % badge, hover image, quick add to cart
- Product page: sticky gallery, star rating, savings display, "X people are viewing", low-stock alert,
  variant buttons, Buy Now, delivery-date estimate, money-back guarantee, a sticky ATC bar,
  related products, and Product schema
- Cart drawer: free-shipping progress bar, "you might also like" recommendations, and a savings summary
- WhatsApp button and an optional "someone just bought" popup

## Structure
`layout/`, `sections/`, `snippets/`, `templates/`, `assets/`, `config/`, `locales/` — the standard Shopify theme structure.
Everything is customizable from the Shopify theme editor.
